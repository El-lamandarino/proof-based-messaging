    How this was made

    1. Reviewers are matched to buyer personas by job title. Code
    2. Themes and word-for-word quotes are extracted from the reviews. AI
    3. Counts, trends and persona splits are calculated, and every quote is checked against the source text. Code
    4. Positioning and messaging are written only from verified themes. AI
    5. A separate strict pass checks every claim against the quotes, and tests the SDR pitch. AI + code
